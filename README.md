# AI Fraud Detection System

AI-powered real-time anomaly detection system for banking and underwriting.

## Features
- OCR Text Extraction
- PDF Metadata Analysis
- Fraud Risk Scoring
- Suspicious Keyword Detection
- Authenticity Score
- AI Explanations
- Underwriting Insights
- Downloadable Fraud Reports

## Technologies Used
- Python
- Streamlit
- EasyOCR
- PyMuPDF
- Pandas

## Use Case
Detects document tampering, forgery, and suspicious anomalies in financial/legal documents during underwriting.
